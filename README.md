# Ariapura cinema pitch (5 variants)

Speculative pitch for an Italian HVAC air-sanitation company: five cinematic landing-page variants in one HTML file with a top-right switcher (V1 to V5). Replaces the earlier `skynetlabs-ariapura-relaunch`.

| Variant | Look |
|---|---|
| V1 Aether | WebGL particle field (Three.js from CDN), dark |
| V2 Solomeo | Editorial, cream and brass |
| V3 Cleanroom | Clinical, monospace |
| V4 Terra Nuova | Landscape parallax, sage and brass |
| V5 Cinecitta | 2.39:1 letterbox, teal and orange grade |

## In the repo

- `index.html`: all five variants, choice saved in `localStorage`
- `docs/`: research, a 90-day growth-plan outline, and the Italian pitch message

## Run it

Open `index.html`, or deploy with Vercel.

Copy is Italian. Unsolicited pitch; the company has not adopted it.

Live: https://skynetlabs-ariapura-cinema.vercel.app
